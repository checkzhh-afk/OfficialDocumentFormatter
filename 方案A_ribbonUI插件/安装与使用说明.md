# 方案 A：Ribbon 插件安装与使用

完整说明见项目根目录 `使用说明.md`。

## 安装

1. 完全关闭 WPS。
2. 在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\方案A_ribbonUI插件\install_wps_addin.ps1"
```

3. 重新打开 WPS 文字。
4. 确认顶部出现“公文格式”选项卡。

更新 `OfficialDocumentFormat_0.01\main.js` 后，需要重新运行安装脚本并重启 WPS。

正式 `main.js` 已使用纯 ASCII Unicode 转义以规避 WPS 宏编辑器编码损坏。不要把文件另存为 ANSI/GBK，也不要将 `\uXXXX` 批量还原为中文源码。

## 操作

方案A使用WPS顶部Ribbon按钮，所有按钮均为单击，不需要双击。

1. 全文处理：打开待处理公文，确认它是当前活动文档，单击“公文格式”中的“全文格式化”。
2. 局部处理：在当前活动文档中选中文字或完整段落，再单击标题、正文、日期、附件等对应按钮。
3. 页码处理：单击“设置公文页码”。

全文格式化会在正文和每个附件中分别识别落款单位、日期。附件末尾识别到的相邻落款单位和日期，使用与正文落款、成文日期相同的格式规则。

方案A始终处理当前活动文档或当前选区，不扫描插件所在文件夹，不弹出同目录文件列表，也不能从多个已打开文档中选择另一个目标。需要同目录扫描、跨文档选择或在控制台中执行时，应使用方案B。

每次更新 `OfficialDocumentFormat_0.01\main.js` 或 `ribbon.xml` 后，都必须重新运行安装脚本并完全退出、重启WPS；仅修改项目目录中的文件不会自动更新WPS已安装副本。
