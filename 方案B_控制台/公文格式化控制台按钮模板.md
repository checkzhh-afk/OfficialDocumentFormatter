# 公文格式化控制台

本文件用于制作 WPS JS 宏控制台。请将本文件、`公文格式化控制台WPS宏.js` 和待处理公文放在同一文件夹。

## 使用顺序

1. 在 WPS JS 宏管理器中导入 `公文格式化控制台WPS宏.js`。
2. 优先运行 `ConsoleRunMenu`，通过输入序号选择操作。
3. 如果当前 WPS 支持给形状或按钮绑定 JS 宏，也可以在控制台文档中插入按钮或形状。
4. 按下表把按钮绑定到对应函数。
5. 点击“选择目标文档”，选择同文件夹内需要处理的公文。
6. 点击“全文格式化”，目标文档会打开并执行全量格式调整，执行后保持打开。
7. 局部调整时，先在目标文档中选中段落，再点击“记录当前选区”。
8. 回到控制台点击对应格式按钮，或运行 `ConsoleRunMenu` 输入对应序号。每次重新选择段落后，都要再次记录选区。

如果信创 Linux 版 WPS 文件选择框不可用，可以先手动打开目标文档，再运行 `ConsoleUseActiveDocument`，或在菜单中输入 `0`。该操作会显示当前文档名称确认，并防止把控制台模板误设为目标。

## 基础操作按钮

| 按钮文字 | 绑定函数 | 用途 |
| --- | --- | --- |
| 操作菜单 | `ConsoleRunMenu` | 通过输入序号选择所有操作，兼容性最好 |
| 当前文档设为目标 | `ConsoleUseActiveDocument` | 把当前活动文档设为待处理目标，适合文件选择框不可用时使用 |
| 选择目标文档 | `ConsoleSelectTargetDocument` | 手动选择要处理的 Word/WPS 文档 |
| 打开目标文档 | `ConsoleOpenTargetDocument` | 打开已选择的目标文档并切换过去 |
| 记录当前选区 | `ConsoleCaptureTargetSelection` | 保存目标文档当前选中段落，供控制台局部格式按钮使用 |
| 全文格式化 | `ConsoleFormatTargetDocument` | 对目标文档执行全量格式调整 |
| 居中页码 | `ConsoleApplyPageNumberFormat` | 设置目标文档页脚居中页码，页码使用 Times New Roman |

## 选区格式按钮

| 按钮文字 | 绑定函数 | 用途 |
| --- | --- | --- |
| 大标题 | `ConsoleApplyTitleFormat` | 对选中段落套用公文标题格式 |
| 主送单位 | `ConsoleApplyMainRecipientFormat` | 对选中段落套用主送单位格式 |
| 正文 | `ConsoleApplyBodyFormat` | 对选中段落套用正文格式 |
| 一级标题 | `ConsoleApplyLevel1HeadingFormat` | 对选中段落套用一级标题格式 |
| 二级标题 | `ConsoleApplyLevel2HeadingFormat` | 对选中段落套用二级标题格式 |
| 三级标题 | `ConsoleApplyLevel3HeadingFormat` | 对选中段落套用三级标题格式 |
| 四级标题 | `ConsoleApplyLevel4HeadingFormat` | 对选中段落套用四级标题格式 |
| 一是/二是加粗 | `ConsoleApplyYiShiFormat` | 对选中段落内“一是、二是”等词加粗 |
| 成文日期 | `ConsoleApplyDateFormat` | 对选中段落套用成文日期格式 |
| 落款单位 | `ConsoleApplySignatureFormat` | 对选中段落套用落款单位格式 |
| 附件说明 | `ConsoleApplyAttachmentNoteFormat` | 对“附件：1...”行套用附件说明格式 |
| 附件说明续行 | `ConsoleApplyAttachmentNoteContinuationFormat` | 对附件说明后续行套用对齐格式 |
| 附件序号 | `ConsoleApplyAttachmentSequenceFormat` | 对附件正文中的“附件1”序号行套用格式 |
| 附件标题 | `ConsoleApplyAttachmentTitleFormat` | 对附件标题套用居中标题格式 |

## 兼容性说明

本方案使用 WPS JS 宏，不使用 VBA、Windows COM 或 ActiveX，目标兼容 Windows WPS 和信创 Linux WPS。不同 WPS 版本对文件选择框支持不同；如果无法弹出选择框，脚本会提示手工输入目标文档完整路径；若路径输入也不可用，请先手动打开目标文档并使用“当前文档设为目标”。
