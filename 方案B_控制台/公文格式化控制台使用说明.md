# 公文格式化控制台使用说明

## 文件

- 核心控制台脚本：`公文格式化控制台WPS宏.js`
- 原全文宏脚本：`公文格式化WPS宏.js`

控制台脚本已经包含完整格式化逻辑，可单独导入 WPS JS 宏使用。

## 适用环境

该方案使用 WPS JS 宏，不使用 VBA、Windows COM、ActiveX 文件系统对象，目标是兼容 Windows WPS 和信创 Linux WPS。不同 WPS 版本的文件选择对话框能力可能不同；如果文件选择框不可用，脚本会退化为手工输入目标文档完整路径。若文件选择和路径输入都不可用，请先手动打开目标文档，再使用“当前文档设为目标”。

## 推荐使用流程

1. 新建或打开一个“公文格式化控制台”文档。
2. 在 WPS JS 宏管理器中导入 `公文格式化控制台WPS宏.js`。
3. 最稳妥的方式是先运行 `ConsoleRunMenu`，通过输入序号选择操作。
4. 如果当前 WPS 支持给形状或按钮绑定 JS 宏，也可以在控制台文档中插入形状或按钮，并把按钮分别绑定到“按钮函数清单”中的函数名。
5. 点击 `ConsoleSelectTargetDocument` 或在菜单中输入 `1`，选择同文件夹下需要处理的 `.docx/.doc/.wps` 文件。
6. 点击 `ConsoleFormatTargetDocument` 或在菜单中输入 `3`，打开目标文档并执行全文格式化。执行完成后目标文档保持打开。
7. 如需局部调整，在目标文档里选中对应段落，点击 `ConsoleCaptureTargetSelection`，或在菜单中输入 `19` 记录当前选区。
8. 再回到控制台点击相应格式按钮，或运行 `ConsoleRunMenu` 输入对应序号。每次更换局部调整位置后，都要重新记录选区。

如果信创 Linux 版 WPS 文件选择框不可用，可以先手动打开目标文档，再运行 `ConsoleUseActiveDocument`，或在 `ConsoleRunMenu` 中输入 `0`，把当前活动文档设为目标文档。该操作会显示当前文档名称以供确认，并会拒绝把名称包含“公文格式化控制台”的模板误设为目标。

## 注意事项

- 局部格式按钮优先使用已记录的目标文档选区；记录后的选区可跨控制台与目标文档切换保留。
- 如果未记录选区，宏会尝试使用目标文档当前选区；失败时会提示重新选择并记录。
- 对“落款单位”执行局部格式时，宏会自动识别目标文档的成文日期，用日期位置计算落款的横向居中位置。
- 控制台文档、脚本和待处理文档建议放在同一文件夹，便于选择和迁移。
- 全文格式化会先确认是否继续，再询问是否清除全文格式。
- 页码会放在页脚居中，页码字段使用 `Times New Roman`、非加粗且保留原字号；宏会替换原有页码字段，不会把整个页脚的文字改成页码字体。

## 按钮函数清单

| 按钮名称建议 | 绑定函数 |
| --- | --- |
| 操作菜单 | `ConsoleRunMenu` |
| 当前文档设为目标 | `ConsoleUseActiveDocument` |
| 选择目标文档 | `ConsoleSelectTargetDocument` |
| 打开目标文档 | `ConsoleOpenTargetDocument` |
| 记录当前选区 | `ConsoleCaptureTargetSelection` |
| 全文格式化 | `ConsoleFormatTargetDocument` |
| 大标题 | `ConsoleApplyTitleFormat` |
| 主送单位 | `ConsoleApplyMainRecipientFormat` |
| 正文 | `ConsoleApplyBodyFormat` |
| 一级标题 | `ConsoleApplyLevel1HeadingFormat` |
| 二级标题 | `ConsoleApplyLevel2HeadingFormat` |
| 三级标题 | `ConsoleApplyLevel3HeadingFormat` |
| 四级标题 | `ConsoleApplyLevel4HeadingFormat` |
| 一是/二是加粗 | `ConsoleApplyYiShiFormat` |
| 成文日期 | `ConsoleApplyDateFormat` |
| 落款单位 | `ConsoleApplySignatureFormat` |
| 附件说明 | `ConsoleApplyAttachmentNoteFormat` |
| 附件说明续行 | `ConsoleApplyAttachmentNoteContinuationFormat` |
| 附件序号 | `ConsoleApplyAttachmentSequenceFormat` |
| 附件标题 | `ConsoleApplyAttachmentTitleFormat` |
| 居中页码 | `ConsoleApplyPageNumberFormat` |
