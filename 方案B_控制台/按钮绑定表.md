# 方案 B：控制台按钮绑定表

正式控制台：`公文格式控制台.docm`

源码主本：`公文格式化控制台WPS宏.js`

控制台中的每项操作都是WPS复合 `MACROBUTTON` 字段，显示文字统一为“双击：操作名称”。双击完整动作文字执行，不要双击单元格空白处。

## 文档操作按钮

| 文档显示文字 | JS 宏函数 | 作用 |
| --- | --- | --- |
| 双击：同目录一键格式化 | `ConsoleFormatFolderDocument` | 扫描控制台同文件夹，排除控制台自身；多个候选时自动打开可用上下方向键操作的原生文件选择框，选择后全文格式化；完成后保持目标文档为活动文档 |
| 双击：操作菜单 | `ConsoleRunMenu` | 打开序号菜单，兼容没有按钮的环境 |
| 双击：选择同目录目标 | `ConsoleSelectTargetDocument` | 只选择并记录同目录目标 |
| 双击：打开已选目标 | `ConsoleOpenTargetDocument` | 打开并激活已记录目标 |
| 双击：格式化已选目标 | `ConsoleFormatTargetDocument` | 对已记录目标执行全文格式化；完成后保持目标文档为活动文档 |
| 双击：选择已打开文档 | `ConsoleChooseOpenDocument` | 从已打开的非控制台文档中选择目标 |
| 双击：查看当前目标 | `ConsoleShowTargetDocument` | 显示当前目标文档或路径 |
| 双击：脚本自检 | `ConsoleSyntaxCheck` | 初始化并检查控制台脚本 |

## 选区格式按钮

使用方法：在目标公文中选中文字或完整段落，切回控制台后双击按钮。

| 文档显示文字 | JS 宏函数 | 作用 |
| --- | --- | --- |
| 双击：大标题 | `ConsoleApplyTitleFormat` | 宋体、二号、加粗、居中 |
| 双击：主送单位 | `ConsoleApplyMainRecipientFormat` | 主送单位格式 |
| 双击：正文 | `ConsoleApplyBodyFormat` | 正文格式 |
| 双击：一级标题 | `ConsoleApplyLevel1HeadingFormat` | 一级标题格式 |
| 双击：二级标题 | `ConsoleApplyLevel2HeadingFormat` | 二级标题格式 |
| 双击：三级标题 | `ConsoleApplyLevel3HeadingFormat` | 三级标题格式 |
| 双击：四级标题 | `ConsoleApplyLevel4HeadingFormat` | 四级标题格式 |
| 双击：一是/二是加粗 | `ConsoleApplyYiShiFormat` | 仅对“一是”“二是”等句式加粗 |
| 双击：成文日期 | `ConsoleApplyDateFormat` | 成文日期格式 |
| 双击：落款单位 | `ConsoleApplySignatureFormat` | 落款单位格式 |
| 双击：附件说明 | `ConsoleApplyAttachmentNoteFormat` | “附件：...”说明行格式 |
| 双击：附件说明续行 | `ConsoleApplyAttachmentNoteContinuationFormat` | 附件说明续行格式 |
| 双击：附件序号 | `ConsoleApplyAttachmentSequenceFormat` | “附件1”“附件2”等序号行 |
| 双击：附件标题 | `ConsoleApplyAttachmentTitleFormat` | 附件序号下一行的附件名称 |
| 双击：公文页码 | `ConsoleApplyPageNumberFormat` | 4 号宋体 `— 1 —`；奇数页右空一字、偶数页左空一字；一字线上边缘距版心下边缘 7mm |

## 兼容菜单序号

运行 `ConsoleRunMenu` 后输入：

| 序号 | 操作 |
| --- | --- |
| 0 | 同目录选择并全文格式化 |
| 1 | 同目录选择目标文档 |
| 2 | 打开目标文档 |
| 3 | 全文格式化 |
| 4-18 | 对应选区格式按钮 |
| 19 | 记录已打开文档的当前选区 |
| 20 | 同目录选择并全文格式化 |
| 21 | 查看当前目标 |
| 22 | 从已打开文档中选择目标 |

按钮方式会自动读取打开文档中保留的选区；菜单序号 `19` 仅作为旧版或特殊 WPS 环境的兼容入口。
