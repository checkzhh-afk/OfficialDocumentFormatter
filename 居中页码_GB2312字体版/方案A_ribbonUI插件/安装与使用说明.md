# 方案 A：Ribbon 插件安装与使用

## 安装

1. 完全关闭所有 WPS 窗口。
2. 在本目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File ".\install_wps_addin.ps1"
```

3. 重新打开 WPS 文字。
4. 顶部应出现“公文格式·GB2312”选项卡。

安装脚本使用独立插件名 `OfficialDocumentFormatGB2312`，并保留 `publish.xml` 中已经安装的其他 WPS JS 插件，因此可与原版方案 A 共存。

更新 `OfficialDocumentFormatGB2312_0.01\main.js` 或 `ribbon.xml` 后，必须重新运行安装脚本并彻底重启 WPS。

## 全文格式化

1. 打开需要处理的公文。
2. 确认该公文是当前活动文档。
3. 单击“公文格式·GB2312”中的“全文格式化”。

全文格式化会同时处理：

- 公文标题、正文、各级标题、日期、落款和附件；附件末尾识别到的落款、日期按正文对应规则处理。
- 表格中英文字体和四号（14 磅）字号。
- 脚注和尾注中英文字体及小四（12 磅）字号。
- 居中的 `—1—`、`—2—` 形式页码。

## 局部格式

在当前活动公文中选中文字或完整段落，再单击对应按钮。方案 A 只处理当前活动文档，不会从多个已打开文档中另行选择目标。

对象类按钮：

- “设置表格字体和字号”：处理当前文档全部表格，中文为 `仿宋_GB2312`，英文为 `Times New Roman`，字号为四号（14 磅），保留粗体、对齐等其他格式。
- “设置脚注和尾注中英文字体”：处理当前文档全部脚注和尾注，中文为 `仿宋_GB2312`，英文为 `Times New Roman`，字号为小四（12 磅）；不处理页码，保留粗体等其他格式。
- “设置居中页码”：设置 4 号（14 磅）宋体半角阿拉伯数字居中页码，格式为 `—1—`、`—2—`，数字与一字线之间不留空格；两侧使用一字线 `—`，不是短横线或减号 `-`。同时保留奇偶页不同结构、跨节连续、距版心下边缘 7mm 等要求。

## 主要字体

- 大标题、附件标题：`方正小标宋简体`，22 磅，不额外加粗。
- 正文及常规公文内容：`仿宋_GB2312`。
- 二级标题：`楷体_GB2312`，三号加粗。
- 英文和数字的西文字体：`Times New Roman`，页码除外。

指定字体未安装时，WPS 可能自动替换字体。正式使用前应安装并核对 `仿宋_GB2312`、`楷体_GB2312` 和 `方正小标宋简体`。

## 源码兼容要求

正式 `main.js` 使用纯 ASCII、CRLF 和 ES5 语法，中文以 `\uXXXX` 形式保存，用于规避 WPS 宏编辑器编码损坏。不要把源码另存为 ANSI/GBK，也不要批量把 Unicode 转义还原为中文。
