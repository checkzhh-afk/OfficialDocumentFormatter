# 方案 B：带按钮的 WPS JSA 控制台

## 正式文件

- `公文格式控制台_居中页码_GB2312.docm`：正式控制台，内嵌宏并带 25 个可双击按钮。
- `公文格式化控制台WPS宏.js`：宏源码主本。
- `生成公文格式控制台文档.js`：根据源码重新生成 `DOCM`。
- `按钮绑定表.md`：按钮、宏入口和兼容菜单序号对照。

正常使用只需复制并打开 `公文格式控制台_居中页码_GB2312.docm`，不需要手动导入 `.js`。

## 首次使用

1. 先备份待处理公文。
2. 把 `公文格式控制台_居中页码_GB2312.docm` 复制到待处理公文所在文件夹。
3. 用 WPS 文字打开控制台。
4. 按本机安全策略允许宏/JSA 运行。
5. 在完整的“双击：操作名称”文字上双击；不要双击单元格空白处。

WPS 第一次单击可能只选中宏字段，双击完整动作文字才会执行。

## 同目录一键格式化

双击“双击：同目录一键格式化”。

- 只有一个目标文件：自动打开并全文格式化。
- 有多个目标文件：打开 WPS 原生文件选择框。用上下方向键移动，按 `Enter` 确认，也可以使用鼠标。
- 原生文件选择框不可用时：才会显示文件名列表并要求输入序号。
- 完成后：目标公文保持为当前活动文档，不切回控制台。

支持 `.doc`、`.docx`、`.docm`、`.wps`、`.wpt`。控制台自身、改名后的控制台宏文档和 `~$` 开头的临时文件都会被排除。

全文格式化会同时处理公文段落、附件、表格、脚注/尾注和居中页码。每个附件末尾识别到的相邻落款单位和日期，会按正文落款、成文日期的规则处理。

## 分步处理目标

需要先选文件、稍后处理时：

1. 双击“双击：选择同目录目标”。
2. 双击“双击：打开已选目标”。
3. 双击“双击：格式化已选目标”。
4. 双击“双击：查看当前目标”检查当前记录。

目标文档已经打开时，可双击“双击：选择已打开文档”。

## 局部格式调整

1. 打开需要调整的公文。
2. 在公文中选中文字或完整段落，并保持该文档打开。
3. 切回控制台。
4. 双击“大标题”“正文”“二级标题”等对应动作。

同时打开多个公文时，脚本会列出文档名称及“已选中文字/未选中文字”状态，要求输入序号。局部按钮会读取所选公文窗口中保留的实际选区；同一文档有多个窗口时，优先使用存在非折叠选区的窗口。

表格、脚注和页码按钮不要求先选择文字，会对用户选定的已打开文档整体执行：

- “表格字体字号”：中文 `仿宋_GB2312`，英文 `Times New Roman`，四号（14 磅）；保留粗体、对齐等其他格式。
- “脚注字体”：脚注和尾注中文 `仿宋_GB2312`，英文 `Times New Roman`，小四（12 磅）；不处理页码，保留粗体等其他格式。
- “居中页码”：4 号（14 磅）宋体半角阿拉伯数字，格式为 `—1—`、`—2—`，数字与一字线之间不留空格；两侧使用一字线 `—`，不是短横线或减号 `-`。所有页居中，并保留奇偶页不同结构、跨节连续和一字线上边缘距版心下边缘 7mm 等要求。

## 字体要求

电脑必须安装 `仿宋_GB2312`、`楷体_GB2312` 和 `方正小标宋简体`。缺少字体时，WPS 会发生字体替代。

## 无法使用文档按钮时

1. 关闭 WPS 中已经打开的旧控制台。
2. 重新打开本目录最新生成的 `公文格式控制台_居中页码_GB2312.docm`。
3. 双击“脚本自检”。

如果当前 WPS 版本不能执行 `MACROBUTTON`，可把 `公文格式化控制台WPS宏.js` 导入 WPS JS 宏项目，再运行：

- `ConsoleSyntaxCheck`：检查宏是否完整加载。
- `ConsoleRunMenu`：打开兼容序号菜单。

## 更新控制台

修改宏源码后，在本版根目录执行：

```powershell
node ".\方案B_控制台\生成公文格式控制台文档.js"
```

生成器会覆盖生成 `公文格式控制台_居中页码_GB2312.docm`。正式 JS 保持纯 ASCII、CRLF 和 ES5 语法，不要改成 ANSI/GBK，也不要把 `\uXXXX` 批量还原为中文。

## 保存

脚本不会自动覆盖保存目标文档。检查格式后手动保存或另存为。
