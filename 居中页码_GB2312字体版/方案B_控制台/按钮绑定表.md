# 方案 B 控制台按钮绑定表

正式控制台：`公文格式控制台_居中页码_GB2312.docm`

每项操作都是 WPS 复合 `MACROBUTTON` 字段。双击完整的“双击：操作名称”文字执行。

## 文档操作

| 显示文字 | JS 宏函数 | 作用 |
| --- | --- | --- |
| 双击：同目录一键格式化 | `ConsoleFormatFolderDocument` | 同目录选择目标并执行全文格式化；多文件时优先用可键盘操作的原生文件选择框 |
| 双击：操作菜单 | `ConsoleRunMenu` | 打开兼容序号菜单 |
| 双击：选择同目录目标 | `ConsoleSelectTargetDocument` | 选择并记录同目录目标，不立即格式化 |
| 双击：打开已选目标 | `ConsoleOpenTargetDocument` | 打开并激活已记录目标 |
| 双击：格式化已选目标 | `ConsoleFormatTargetDocument` | 对已记录目标执行全文格式化 |
| 双击：选择已打开文档 | `ConsoleChooseOpenDocument` | 从已打开的非控制台文档中选择目标 |
| 双击：查看当前目标 | `ConsoleShowTargetDocument` | 显示当前目标文档或路径 |
| 双击：脚本自检 | `ConsoleSyntaxCheck` | 初始化并检查控制台脚本 |
| 双击：表格字体 | `ConsoleApplyTableTextFormat` | 当前所选文档全部表格：中文 `仿宋_GB2312`，英文 `Times New Roman` |
| 双击：脚注字体 | `ConsoleApplyFootnoteTextFormat` | 当前所选文档全部脚注和尾注中英文字体，不处理页码 |
| 双击：居中页码 | `ConsoleApplyPageNumberFormat` | 设置 14 磅宋体 `— 1 —` 居中页码 |

## 选区格式

| 显示文字 | JS 宏函数 | 作用 |
| --- | --- | --- |
| 双击：大标题 | `ConsoleApplyTitleFormat` | `方正小标宋简体`、二号、不额外加粗、居中 |
| 双击：主送单位 | `ConsoleApplyMainRecipientFormat` | 主送单位格式 |
| 双击：正文 | `ConsoleApplyBodyFormat` | `仿宋_GB2312` 正文格式 |
| 双击：一级标题 | `ConsoleApplyLevel1HeadingFormat` | 黑体、三号 |
| 双击：二级标题 | `ConsoleApplyLevel2HeadingFormat` | `楷体_GB2312`、三号、加粗 |
| 双击：三级标题 | `ConsoleApplyLevel3HeadingFormat` | `仿宋_GB2312`、三号、加粗 |
| 双击：四级标题 | `ConsoleApplyLevel4HeadingFormat` | `仿宋_GB2312`、三号 |
| 双击：一是/二是加粗 | `ConsoleApplyYiShiFormat` | 只加粗“一是”“二是”等标记 |
| 双击：成文日期 | `ConsoleApplyDateFormat` | 成文日期格式 |
| 双击：落款单位 | `ConsoleApplySignatureFormat` | 落款单位格式 |
| 双击：附件说明 | `ConsoleApplyAttachmentNoteFormat` | “附件：...”说明行 |
| 双击：附件说明续行 | `ConsoleApplyAttachmentNoteContinuationFormat` | 附件说明续行 |
| 双击：附件序号 | `ConsoleApplyAttachmentSequenceFormat` | “附件1”“附件2”等序号行 |
| 双击：附件标题 | `ConsoleApplyAttachmentTitleFormat` | 附件序号下一行的标题，使用 `方正小标宋简体` |

## 兼容菜单序号

| 序号 | 操作 |
| --- | --- |
| 0、20 | 同目录选择并全文格式化 |
| 1 | 同目录选择目标文档 |
| 2 | 打开目标文档 |
| 3 | 全文格式化 |
| 4-18 | 原有各选区格式及居中页码 |
| 19 | 记录已打开文档的当前选区 |
| 21 | 查看当前目标 |
| 22 | 从已打开文档中选择目标 |
| 23 | 表格中英文字体 |
| 24 | 脚注和尾注中英文字体 |
